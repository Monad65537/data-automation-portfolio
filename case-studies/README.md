# Data Automation Portfolio — Case Studies

A collection of reproducible demonstrations of Python-based spreadsheet processing and business data automation.

All demonstrations use synthetic data and do not represent paid client engagements.

## Customer Data Cleaning and Validation

A 1,000-record customer dataset processed using DataClean Pro.

- 871 accepted records
- 129 flagged records
- Structured rejection reasons
- CSV outputs and JSON quality report

[View case study](01-data-cleaning/CASE_STUDY.md)

## Automated Sales Reporting

A transaction-level sales demonstration generated using SalesReport Auto.

- 7 accepted transactions
- USD 435.75 net revenue
- Five-sheet Excel report
- Monthly, branch, and data-quality reporting

[View case study](02-sales-reporting/CASE_STUDY.md)

## Verification

Both case studies include synthetic inputs and program-generated outputs. The source repositories contain implementation details, automated tests, and usage instructions.

Results describe the demonstrated datasets and should not be generalized to arbitrary client data.
